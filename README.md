# Hi, I'm Arman

I build practical AI tools and full-stack web apps. I'm a Computer Engineering student at **Politecnico di Torino**.

## Selected projects

### [armap](https://github.com/Armannss/armap)
A Claude Code plugin that gives the agent a compact, ranked map of a codebase, with queries for file dependencies and symbol references. Plain Node.js, no runtime dependencies, MIT licensed.

### [Armanly](https://github.com/Armannss/speak-and-learn) · [Try the app](https://armannss.github.io/speak-and-learn/)
An English learning app with short lessons, spaced-repetition flashcards and speaking practice. Works offline after the first visit and saves progress in your browser. Built with HTML, CSS and JavaScript.

### [Parsilon Part](https://github.com/Armannss/Parsilon-web-application-mobile-shell)
An auto-parts shop with an admin panel and an AI assistant that searches the live catalogue for compatible parts. Built with Next.js, TypeScript, Prisma, PostgreSQL and the Claude API.

### NEXTRIBE · Private project
A Persian, mobile-first growth club app with daily missions across six life areas, progress tracking, a shared leaderboard and personal reminders. Includes a Telegram membership bot and an admin dashboard for managing members and content. Built with Next.js, React, TypeScript, PostgreSQL and Prisma.
